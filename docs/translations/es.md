### Title (Título — máx. 45 caracteres)

```
BookmarkLab - Gestor de Marcadores
```

### Summary / Short Description (Descripción corta — máx. 132 caracteres)
```
Organizador visual de marcadores: elimine duplicados, agrupe inteligentemente, limpie URLs de rastreo y organice sus marcadores.
```

### Detailed Description (Descripción detallada)
```
BookmarkLab es un espacio de trabajo rápido y visual diseñado para organizar sus marcadores de Chrome con total tranquilidad.

En lugar de aplicar cambios destructivos directamente, BookmarkLab utiliza un modelo seguro de preparación y confirmación: todas las modificaciones se realizan primero en la memoria, permitiéndole revisar exactamente qué se moverá, renombrará o eliminará antes de sincronizar nada con su navegador.

CARACTERÍSTICAS PRINCIPALES:

✦ Importación Universal de Marcadores
Migre sus marcadores fácilmente utilizando archivos estándar de respaldo HTML o JSON con soporte completo para arrastrar y soltar. Elija entre crear una carpeta dedicada aislada, fusionar con carpetas existentes o reemplazar el espacio de trabajo.

✦ Detección y Limpieza de Duplicados
Identifique marcadores repetidos con normalización de URLs. Elimine copias redundantes con un solo clic conservando automáticamente la copia más antigua.

✦ Agrupación Inteligente Automática
Organice cientos de marcadores desordenados en segundos agrupándolos por nombre de dominio (GitHub, YouTube, etc.) o por categorías temáticas (Herramientas de Desarrollo, Multimedia, Investigación, Finanzas, etc.).

✦ Limpieza de URLs de Rastreo
Elimine automáticamente parámetros publicitarios molestos como utm_source, fbclid, gclid, ref y más de 30 etiquetas de seguimiento para mantener sus enlaces limpios y privados.

✦ Verificación de Enlaces Rotos
Compruebe si sus marcadores guardados siguen activos o si devuelven errores, detectando enlaces caídos para actualizarlos o eliminarlos.

✦ Modelo Seguro de Preparación y Sincronización
Nada se modifica en su navegador hasta que usted lo confirme. Revise un desglose detallado de todos los cambios con el botón "Sincronizar Marcadores".

✦ Copia de Seguridad con un Solo Clic
Descargue una copia de seguridad HTML estándar de todos sus marcadores antes de realizar cualquier reorganización importante.

✦ Diseño Minimalista y Personalizable
Superficie moderna inspirada en herramientas profesionales, soporte para modo oscuro y claro, y 5 elegantes acentos de color pastel.

✦ 100% Privado y Local
BookmarkLab funciona completamente en su navegador. No recopila datos, no incluye rastreadores ni envía información a ningún servidor externo.
```
