# Chrome Web Store — German (Deutsch)

### Title (Titel — max. 45 Zeichen)
```
BookmarkLab - Lesezeichen-Manager
```

### Summary / Short Description (Kurzbeschreibung — max. 132 Zeichen)
```
Live-Lesezeichen-Manager: Duplikate entfernen, intelligent gruppieren, Tracking-URLs bereinigen und Lesezeichen in Chrome ordnen.
```

### Detailed Description (Ausführliche Beschreibung)
```
BookmarkLab ist ein schneller, visueller Arbeitsbereich für Ihre Chrome-Lesezeichen – mit einem sicheren Staging-Modell, das Ihre Daten zuverlässig schützt.

Anstatt Änderungen sofort und unumkehrbar in Ihrem Browser vorzunehmen, bearbeitet BookmarkLab Lesezeichen zunächst im Arbeitsspeicher. Sie sehen eine exakte Vorschau aller Verschiebungen, Umbenennungen und Löschungen, bevor ein einziges Lesezeichen tatsächlich synchronisiert wird.

HAUPTFUNKTIONEN:

✦ Universeller Lesezeichen-Import
Migrieren Sie Ihre Lesezeichen mühelos aus standardmäßigen HTML- oder JSON-Sicherungsdateien per Drag-and-Drop. Wählen Sie zwischen einem isolierten Ordner, dem Zusammenführen in bestehende Strukturen oder dem vollständigen Ersetzen des Arbeitsbereichs.

✦ Duplikate erkennen & bereinigen
Findet doppelt gespeicherte Lesezeichen anhand normalisierter URLs. Überflüssige Kopien lassen sich mit einem Klick entfernen, wobei das älteste Lesezeichen automatisch erhalten bleibt.

✦ Automatische Kategorisierung
Sortiert Hunderte unsortierter Lesezeichen in Sekundenschnelle automatisch nach Domain (z. B. GitHub, YouTube) oder intelligenten Themengruppen (Entwickler-Tools, Medien, Recherche, Finanzen etc.).

✦ Tracking-Parameter aus URLs entfernen
Entfernt lästige Marketing-Parameter wie utm_source, fbclid, gclid und über 30 weitere Tracking-Tags aus allen gespeicherten URLs für mehr Privatsphäre und saubere Links.

✦ Link-Verfügbarkeitsprüfung
Prüft im Hintergrund, ob gespeicherte Webseiten noch erreichbar sind oder tote Links (Fehler 404 etc.) vorliegen, damit Sie veraltete Einträge schnell bereinigen können.

✦ Sicheres Staging- und Synchronisationsmodell
Nichts ändert sich in Ihrem Chrome-Browser, bis Sie es ausdrücklich bestätigen. Ein detaillierter Änderungsbericht zeigt Ihnen alle Aktionen im Voraus.

✦ Ein-Klick-Backup
Laden Sie vor größeren Aufräumarbeiten jederzeit ein vollständiges HTML-Backup Ihrer aktuellen Lesezeichen herunter.

✦ Minimalistisches, ruhiges Design
Klares Interface mit modernem Fokus, nahtlosem Dunkel- und Hellmodus sowie 5 dezenten Pastellfarben für ein angenehmes Arbeiten.

✦ 100 % lokal & privat
BookmarkLab arbeitet vollständig auf Ihrem Rechner. Keine Datenübertragung, keine Cloud, keine Server.
```
