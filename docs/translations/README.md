# Chrome Web Store Listing Translations

This directory contains localized Chrome Web Store metadata for each supported language. When publishing or updating BookmarkLab in the [Chrome Web Store Developer Console](https://chrome.google.com/webstore/devconsole), copy and paste the corresponding Title, Short Description, and Detailed Description for each language:

- [Spanish (`es`)](es.md)
- [Portuguese (`pt_BR`)](pt_BR.md)
- [German (`de`)](de.md)
- [French (`fr`)](fr.md)
- [Simplified Chinese (`zh_CN`)](zh_CN.md)
