Features

Everything your bookmarks need

A full organizer toolkit built for people who have accumulated hundreds (or thousands) of bookmarks over the years.

📥

Universal Bookmark Import

Migrate bookmarks effortlessly from any browser using standard HTML or JSON backup files with drag-and-drop support.

🔒

Safe Staging Model

All edits are made in memory first. A full diff summary shows exactly what will be deleted, moved, or renamed before a single thing changes in your browser.

🎨

Minimalist Pastel Design

Crafted with calm obsidian surfaces, crisp 1px borders, zero flashy neon glows, 5 aesthetic pastel accents, and high-contrast dark and light modes.

🖐️

Drag & Drop Organization

Reorganize bookmarks and folders visually using smooth drag-and-drop support across both the folder tree and main grid workspace.

💾

One-Click Backup

Download your current Chrome bookmarks as an HTML file before making any changes. If something goes wrong, you can restore in seconds.

🔍

Duplicate Finder

Scans all bookmarks and groups identical URLs. Keep the one you want or let the auto-resolver keep the oldest copy and remove the rest.

✨

Auto-Cluster

Automatically sorts bookmarks into folders by domain or topic — GitHub, YouTube, Research, Finance, Shopping — in a single click.

🧹

Clean Tracking URLs

Strips utm_source, fbclid, gclid, and dozens of other marketing parameters from your saved URLs so bookmarks stay clean and shareable.

🔗

Link Health Check

Checks every bookmarked URL to see if it is still reachable. Dead and broken links are flagged so you can delete or update them.

🌍

Multi-Language Support

Fully localized into English, Spanish, Portuguese, German, French, and Simplified Chinese, automatically adapting to your browser language.

How it works

Nothing changes until you say so

BookmarkLab follows a safe stage-and-commit model so you are always in control.

Open or Import

BookmarkLab loads your browser bookmarks into an in-memory workspace, or you can import bookmarks from standard HTML or JSON files.

Organize freely

Drag and drop folders, delete duplicates, run Auto-Cluster, clean tracking URLs, rename items — everything is staged in memory.

Review the diff

Click Sync Bookmarks to see a complete summary of every change — deletions, moves, renames — before anything is committed.

Apply or cancel

Confirm to apply the changes to Chrome, or cancel and keep editing. You can also take a Backup at any point before committing.

🔐

Completely private, by design

BookmarkLab runs entirely inside your browser. No bookmark data, URLs, or titles are ever sent to any server or third party. No account required. No analytics. No telemetry. Your bookmarks stay yours.
