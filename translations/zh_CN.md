### Detailed Description (详细说明)
```
BookmarkLab 是一款专为整理 Chrome 书签打造的高效、可视化工作台，带来从容有序的书签管理体验。

与传统插件直接对浏览器进行不可逆修改不同，BookmarkLab 采用安全的“暂存与提交”机制：所有整理操作均首先在内存中暂存完成，在您点击同步之前，可以清晰预览每一处移动、重命名或删除，确保书签数据万无一失。

核心功能特性：

✦ 通用书签导入
支持直接拖拽标准的 HTML 或 JSON 格式书签备份文件导入。可自由选择放入独立的专属文件夹、合并到现有同名文件夹或完全替换当前工作区。

✦ 重复书签查找与清理
基于智能 URL 规范化算法，精准识别重复保存的网址。一键自动保留最早添加的版本并清除多余副本。

✦ 智能主题与域名自动分类
面对成百上千个杂乱书签，一键按域名（如 GitHub、YouTube、Bilibili 等）或智能主题分类（开发工具、媒体娱乐、学术研究、社交网络、金融理财、资讯新闻等）自动归类建档。

✦ 网址营销跟踪参数清理
自动剔除网址末尾冗余的 utm_source、fbclid、gclid、ref 等 30+ 种跟踪参数，让书签链接清爽整洁，保护您的浏览隐私。

✦ 死链与失效链接检测
后台检测已保存书签的访问状态，快速找出 404 或无法打开的失效链接，助您定期清理过期资源。

✦ 差量对比，安全同步
在点击“同步书签”之前，系统会呈现完整的变更对比清单，所有操作由您全权掌控。

✦ 一键离线备份
在进行大规模整理前，随时一键导出标准 Netscape HTML 备份文件到本地。

✦ 极简质感设计
沉静高级的界面质感，支持高对比度深色/浅色模式切换，并提供 5 种柔和的莫兰迪马卡龙主题色。

✦ 100% 本地运行与隐私保护
BookmarkLab 完全在本地浏览器内存中运行，无需登录，不收集任何数据，无任何远程服务器通信。
```
