# Chrome Web Store — French (Français)

### Title (Titre — max. 45 caractères)
```
BookmarkLab - Gestionnaire de Favoris
```

### Summary / Short Description (Description courte — max. 132 caractères)
```
Organisateur visuel de favoris : supprimez les doublons, regroupez intelligemment, nettoyez les URL de suivi et organisez dans Chrome.
```

### Detailed Description (Description détaillée)
```
BookmarkLab est un espace de travail visuel et ultra-rapide conçu pour organiser vos favoris Chrome en toute tranquillité.

Contrairement aux extensions traditionnelles qui appliquent immédiatement des modifications irréversibles, BookmarkLab fonctionne sur un modèle sécurisé de préparation et confirmation : toutes les actions sont d'abord réalisées en mémoire locale, vous permettant de vérifier exactement chaque déplacement, renommage ou suppression avant la moindre synchronisation.

FONCTIONNALITÉS PRINCIPALES :

✦ Importation Universelle de Favoris
Migrez facilement vos favoris depuis des fichiers de sauvegarde standards au format HTML ou JSON grâce au glisser-déposer. Choisissez entre créer un dossier isolé, fusionner avec les dossiers existants ou remplacer l'espace de travail.

✦ Détection & Suppression des Doublons
Repérez automatiquement les favoris identiques grâce à la normalisation des adresses URL. Nettoyez les copies superflues en un clic tout en conservant la version la plus ancienne.

✦ Regroupement Automatique Intelligent
Organisez des centaines de liens en quelques secondes en les classant automatiquement par nom de domaine (GitHub, YouTube, etc.) ou par thématiques (Outils Développeur, Médias, Recherche, Achats, etc.).

✦ Nettoyage des URL de Suivi
Supprimez automatiquement les paramètres marketing indésirables (utm_source, fbclid, gclid, etc.) pour obtenir des favoris propres, nets et respectueux de votre vie privée.

✦ Vérification des Liens Inaccessibles
Contrôlez rapidement si vos favoris enregistrés sont toujours en ligne ou s'ils renvoient des erreurs 404, afin d'éliminer facilement les liens obsolètes.

✦ Modèle Sécurisé avec Diff Avant Synchronisation
Rien ne change dans votre navigateur tant que vous n'avez pas validé. Consultez le récapitulatif précis des actions via le bouton "Synchroniser les Favoris".

✦ Sauvegarde en Un Clic
Téléchargez une copie complète au format HTML standard avant toute réorganisation importante.

✦ Design Épuré et Personnalisable
Interface moderne inspirée des meilleurs outils de productivité, mode clair et sombre haute lisibilité, et 5 tons pastel apaisants.

✦ 100% Privé et Hors Ligne
BookmarkLab fonctionne exclusivement dans votre navigateur. Aucune donnée n'est collectée, analysée ou envoyée vers des serveurs distants.
```
